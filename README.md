# Amazon Sales Dashboard – Excel

## Project Overview

An interactive Amazon Sales Dashboard built using Microsoft Excel to analyze sales,
profit, orders, payment methods, fulfilment methods, categories and order status.

## Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel Formulas
- Data Analysis

## Key KPIs

- Total Sales
- Total Profit
- Total Units Sold
- Average Order Value
- Profit Margin
- Return Rate
- Cancellation Rate

## Analysis

- Category-wise Sales
- Category-wise Units Sold
- Top 10 Products by Sales
- Sales by Payment Method
- Profit by Payment Method
- Sales by Fulfilment Method
- Profit by Fulfilment Method
- Order Status Analysis
